MOHAMED EMAD — PORTFOLIO
========================

RUN IN VISUAL STUDIO CODE
1. Extract Mohamed_Portfolio.zip.
2. Open Visual Studio Code.
3. Choose File > Open Folder and select the mohamed-portfolio folder.
4. Open index.html.
5. Recommended: install the "Live Server" extension by Ritwick Dey.
6. Right-click index.html and choose "Open with Live Server".
7. Your portfolio opens in your browser. Save edits and the browser refreshes.

You can also double-click index.html to open it without Live Server.

CUSTOMIZE BEFORE PUBLISHING
- Replace the "ME" initials in the profile circle with your own photo.
- Replace the decorative project artwork with screenshots of your actual designs and website.
- Add your restaurant website link when ready.
- Check the contact details before publishing.

FILES
- index.html: page structure and content
- style.css: dark theme, layout, mobile responsiveness
- script.js: Arabic/English toggle and mobile navigation
- assets/: place your photos and screenshots here

No Node.js, build tools, or frameworks are required.
